# MAP: what is where in Mess

Start here instead of searching the repo. One line per folder or file: what it is and when to open it.
**Too big to read whole** is marked ⚠: query it instead (`node tools/peek.mjs`, or search for one name and read those lines).

## Rules and how to work
- `CLAUDE.md`, `AGENTS.md`: short. Point to the feature teardown skill (`.agents/skills/feature-teardown/SKILL.md`), which every app or website feature follows.
- `DESIGN.md`: how Mess looks and behaves (buttons, links, the ? panel). Open before any UI change.
- `SECURITY.md`: what stays on the device, what the app may load. Open before anything that touches data, scripts or the network.
- `PACKS.md`: the pack format. `CONTENT-LICENSE.md`: the licence of Mess's own content. `README.md`: for people, not tasks.
- `AI-HANDOFF.md`: an older long handoff. Mostly history; prefer this map.

## The app (`app/`): plain scripts, no build step, one shared global scope
- `app/index.html`: loads every script in order. `app/404.html` **must stay an exact copy** (it opens addresses like `/app/topic-copd`).
- `app/sw.js`: the offline cache. **Line 1 is the cache version: bump it on any change under `app/`.**
- `app/styles.css`: all styles. Search for the class you need.
- `app/data.js` (50 KB): themes, glossary, OSCE stations, the Links page rows. Search for the constant (`STATIONS`, `GLOSSARY`...).
- `app/js/*.js`: one file per area. Each starts with a one-line comment saying what it does. The ones most jobs touch:
  - `flow.js` the shell, page switching and shared helpers; `store.js` holds `act` (the map every button's `data-a` action is added to); `boot.js` start-up and global listeners (runs last); `route.js` web addresses.
  - `topics.js` topic pages; `story.js` stories, guess-first questions, gaps and source credits; `inpractice.js` In practice pages; `curricula.js` the curriculum views.
  - `practice.js` questions, OSCE, prescribing; `today.js`; `stats.js`; `placement.js`; `profile.js`.
  - `ai.js` every AI provider and the ? panel; `grounding.js` evidence-aware topic answers.
  - `store.js` saving and loading; `safety.js` escaping and checks; `intake.js` every file, paste and pack comes in here; `packs.js`; `import.js`.
- `app/assets/`:
  - ⚠ `topics.js` (29 KB): every topic, drug and In practice item as `Name|also called|area|links|drugs` rows. `node tools/peek.mjs topic "Name"`, `node tools/peek.mjs list drugs`.
  - ⚠ `stories.js` (74 KB): every story. `node tools/peek.mjs story "Name" --outline`. Built ones sit between `// built:<topic>` markers: never edit those, edit the topic's `story.json`.
  - ⚠ `notes.js` (55 KB): short notes per topic. `node tools/peek.mjs notes "Name"`.
  - ⚠ `evidence.js` (1 MB, generated by `tools/build-evidence.mjs`): statements per topic for the topic chat. `node tools/peek.mjs evidence "Name"` (counts; wording only from allowed sources).
  - `curricula.js`: curriculum maps (the GMC content map and schools).
  - ⚠ Vendor files, never open: `mermaid.min.js`, `sql-asm.js`, `pdf*.js`, `jszip.min.js`, `fzstd.js`, `rough.js`, `ts-fsrs.js`.

## The website (repo root)
- `index.html` the home page, `help.html` Help, `site.css`, `site.js`, `site-data.js` (generated by `tools/site-data.mjs`), `site-visits.js` (visit counting, website only), `site-img/`.
- `_headers`, `wrangler.jsonc`: Cloudflare settings.

## Content (`content/`)
- **`content/README.md` is the one place for how statements are written, checked and built into stories.** Open it for any content job.
- `content/rights.json`: the rights register (which sources a model may read). `rights-frozen.json`: what existed when NICE, BTS, SIGN and GOLD were frozen.
- `content/open/<topic>/`: statements from open sources (`statements.csv`), checks (`factcheck.*.csv`, `consensus.csv`), `coverage.md`, `story-plan.md`, `story.json`. Current: `hypertension/`.
- `content/open-sources/<id>.json`: saved open sources with their licence and credit line. ⚠ large: read a sentence with its address, not the file.
- `content/<area>/<condition>/`: the old guideline claims. **Frozen.** Do not open `content/sources/` or the quote columns of `claims.csv`.
- `content/agents.md`: the briefs for writers and checkers (Brief 2 fact check, Brief 3 story check, Brief 4 questions).
- `content/gmc/`, `content/prescribing/`, `queue.csv`, `guideline-queue.csv`: older planning files.

## Tools (`tools/`, run with node from the repo root)
- Open-source content: `fetch-open.mjs` save a source; `check-open.mjs` build and check statements, write coverage; `build-story.mjs` build a story; `ai-factcheck.mjs` the checkers (Action, API or by hand with `--packet`); `consensus.mjs` what two checkers agreed; `check-factcheck.mjs` a check file is real.
- Rights: `rights.mjs` (shared lookup, wording stamps), `check-rights.mjs` (the gate, runs with the tests).
- Questions: `check-questions.mjs`. Packs: `check-packs.mjs`. Links: `check-links.mjs`. Evidence: `build-evidence.mjs`.
- `peek.mjs`: one entry from a big data file (see ⚠ above).
- `find-open.mjs`: search Europe PMC for CC BY articles, and read a saved source one addressed sentence per line (`show <id>`), with set-aside sentences hidden.
- The old guideline process, paused with the NICE stop: `fill-quotes.mjs`, `dump-recs.mjs`, `quotes-from-recs.mjs` (these three refuse NICE, BTS, SIGN and GOLD in code), `sofia-check.mjs`, `pipeline-status.mjs`, `check-claims.mjs` (still runs on GitHub), `meaning.mjs`.

## Tests (`tests/`)
- `NODE_PATH=$(npm root -g) node tests/run.mjs` runs everything (about 3 minutes). Add `--quiet` for one line per failure plus the count, and `--only <name>` for one test.
- Each `*.test.js` says at the top what it checks. `serve.mjs` serves a folder for a browser test.
- `.github/workflows/tests.yml` runs them on pull requests and main.
